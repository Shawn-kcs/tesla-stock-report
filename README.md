## 💻 파일 열람 및 실행 방법

### 1. 로컬 환경에서 직접 열기 (Local Preview)
1. 폴더 내의 [`index.html`](index.html) 또는 [`stock-report.html`](stock-report.html) 파일을 더블 클릭합니다.
2. 또는 웹 브라우저(Chrome, Edge 등) 창으로 파일을 끌어다 놓으면 외부 서버나 인터넷 연결 없이도 즉시 차트와 데이터를 확인하실 수 있습니다.

### 2. GitHub Pages 배포 시 열람 (Pages Deployment)
* 본 저장소가 GitHub Pages에 배포되면, 모든 내부 자원이 상대 경로(`./`)로 연결되어 있어 `https://<사용자명>.github.io/<저장소명>/` 서브 디렉터리 경로 아래에서도 스타일 깨짐이나 파일 경로 오류 없이 정상적으로 동작합니다.
